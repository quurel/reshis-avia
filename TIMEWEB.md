# Размещение на обычном виртуальном хостинге Timeweb

Размещение выполняете вы. Для Flask нужен виртуальный хостинг с Python 3.10 и mod_wsgi. Инструкция рассчитана на размещение сайта в корне домена. Актуальная инструкция провайдера: https://timeweb.com/ru/docs/virtualnyj-hosting/prilozheniya-i-frejmvorki/flask/

## 1. Подготовьте сайт и базу

В панели Timeweb:

- создайте сайт и привяжите домен или доступный технический адрес;
- выберите серверное окружение с Python 3.10/mod_wsgi, если требуется — уточните выбор у поддержки;
- создайте MySQL-базу с кодировкой utf8mb4 и пользователя с правами на неё;
- сохраните имя базы, пользователя, пароль и адрес сервера из панели;
- включите HTTPS/SSL для выбранного адреса.

Названия пунктов панели могут отличаться. В инструкциях ниже `SITE_ROOT` означает папку сайта, содержащую `public_html`; обычно это каталог вида `/home/п/пользователь/папка_сайта`. Не вставляйте этот пример как свой реальный путь.

## 2. Загрузите файлы

Структура должна получиться такой:

```text
SITE_ROOT/
    .venv/
    reshis-avia/
        app.py
        forecast.py
        models.py
        requirements.txt
        .env
        data/
        templates/
        static/
    public_html/
        .htaccess
        index.wsgi
```

Сам проект загрузите в `SITE_ROOT/reshis-avia`, то есть ВНЕ `public_html`. В `public_html` скопируйте только `.htaccess` и `index.wsgi` из папки `deploy`. Так `.env`, CSV и Python-исходники не станут обычными публичными файлами.

Если в `public_html` уже есть стартовый `index.html`, уберите или переименуйте его. Не удаляйте чужие файлы существующего сайта: используйте отдельный сайт/домен для проекта.

## 3. Установите зависимости

По SSH или в консоли хостинга перейдите в настоящий `SITE_ROOT` и выполните:

```bash
python3.10 -m venv .venv
source .venv/bin/activate
python -m pip install -r reshis-avia/requirements.txt
```

Если команда `python3.10` у вашего сервера называется иначе, используйте путь из инструкции или поддержки Timeweb. Версия интерпретатора окружения и версия Python в mod_wsgi должны совпадать. Не устанавливайте зависимости в случайную версию Python.

`index.wsgi` автоматически ищет `.venv` и `reshis-avia` рядом с `public_html`. При другой структуре измените пути в этом файле. Не добавляйте реальный пароль в `index.wsgi`.

## 4. Настройте .env

В папке проекта создайте `.env` по образцу `.env.example`. Сгенерируйте `SECRET_KEY`:

```bash
python -c "import secrets; print(secrets.token_hex(32))"
```

Заполните данные:

```dotenv
SECRET_KEY=ваша_случайная_строка
DB_HOST=адрес_сервера_из_панели
DB_PORT=3306
DB_NAME=имя_базы_из_панели
DB_USER=пользователь_из_панели
DB_PASSWORD=пароль_базы
COOKIE_SECURE=1
```

Для значений с пробелами или специальными символами используйте кавычки по синтаксису dotenv. Пример `DB_PASSWORD='пароль с пробелами'`. Данные в примере не являются готовыми реквизитами.

```bash
chmod 600 reshis-avia/.env
```

`COOKIE_SECURE=1` нужно для HTTPS. С такой настройкой авторизация не работает по обычному HTTP: открывайте именно `https://...`. Значение 0 оставляют только для локальной проверки без HTTPS.

## 5. Создайте таблицы и включите WSGI

```bash
cd reshis-avia
python -m flask --app app:create_app init-db
cd ../public_html
chmod 755 index.wsgi
```

После изменения кода или `.env` перезапустите Python-приложение способом из панели/поддержки Timeweb. Если используется автоматическая перезагрузка по времени изменения скрипта, достаточно обновить `index.wsgi`:

```bash
touch index.wsgi
```

На хостинге НЕ запускайте `flask run` как постоянный сервер. Входная точка — `public_html/index.wsgi`, объект `application`.

## 6. Проверьте результат

- Главная страница открывается по HTTPS, оформление и графическая библиотека загружаются.
- Аккаунт регистрируется; после обновления страницы вход сохраняется.
- После выхода пароль подходит для повторного входа.
- Расчёт базовой цены даёт спрос из колонки `0.5_base_demand` нужного рейса.
- Повышение цены Сочи на 1 000 ₽ уменьшает расчётный спрос на 141 человека.
- Продажи неотрицательны и не превышают мест.
- На графике есть медиана и вместимость; таблица сценариев открывается.
- После выхода запрос расчёта требует входа.
- Даты за пределами 1 июня — 1 июля недоступны.

## Если что-то не работает

- **Ошибка 500 на всех страницах:** посмотрите Error log сайта. Обычно причина в путях `index.wsgi`, несовпадении Python или незаполненном `SECRET_KEY`.
- **Главная открывается, регистрация выдаёт временную недоступность:** проверьте MySQL-реквизиты, права пользователя и выполнение `init-db`.
- **Вход не сохраняется:** проверьте HTTPS и `COOKIE_SECURE`. Не меняйте `SECRET_KEY` при каждом запросе или запуске.
- **403/404 при переходах:** проверьте `.htaccess`, обработчик `.wsgi` и каталог размещения. Сравните с официальной инструкцией Timeweb.
- **Старый прогноз:** убедитесь, что в `data/` ровно один файл, заканчивающийся на `my_forecast.csv`, и перезапустите приложение.
- **Заблокирован вход после многих попыток:** подождите 15 минут. Это ограничение перебора пароля, а не ошибка MySQL.

Реальные пароли и содержимое `.env` не отправляйте в публичную папку сдачи, репозиторий или архив исходников.
